题目：无序数组中寻找第K大的数。
给定整数数组nums和整数k,请返回数组中第k个最大的元素。

---

下标与第几小对等起来。转换为排完序后在i位置的数是什么

改写[[随机选择算法|快排]]的方法.找52位置的数![[Pasted image 20260423142911.png]]

最差：O(n^2);0位，每次打的点都很偏。![[Pasted image 20260423143149.png]]


好的情况：点很正，第一次 n 如果没有命中，左右两侧只走一侧寻找，下一个规模 n/2,复杂度为n+n/2+n/4+n/8+... O(n);


随机控制。与快排的区别是 快排两侧都要跑递归，而这里只选择一侧。复杂度估计 概率论的期望。

```java

public static int findKthLargest(int[] nums,int k){
	return randomizedSelect(nums,nums.length()-k);
}

//如果arr排序的话，在i位置的数字是什么

public static int randomizedSelect(int[] arr,int i){
	int ans=0;
	
	//0 ~ n-1
	//l    r  有范围继续 
	for(int l=0,r=arr.lengh-1;l<=r;){
		
		partition(arr,l,r,arr[l+(int)(Math.random()*(r-l+1))]);
		//       i
		//  first  last
		if(i<first){
			//左边寻找
			r=first-1;
		}else if(i>last){
			l=last+1;
		}else{
			ans=arr[i];
			break;
		}
	}
	return ans;

}

//荷兰国旗问题
public static int first,last;

public static void partition(int[] arr,int l,int r,int x){
	first=l;
	last=r;
	int i=l;
	while(i<=last){
		if(arr[i]==x){
			i++;
		}
		else if(arr[i]<x){
			swap(arr,first++,i++);
		}else{
			swap(arr,i,last--);
		}
	}

}
```
