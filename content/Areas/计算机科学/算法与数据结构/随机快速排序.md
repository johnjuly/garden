void quickSort(int l,int r){
	if(l>=r){
		return;
	}
	
	//l到r上随机选一个位置。
	int x=arr[l+(int)(Math.random()*(r-l+1))];
	
	//划分的位置
	int mid=partition(l,r,x);
	quickSort(l,mid-1);
	quickSort(mid+1,r);

}

### 划分


```java
//已知arr[l...r]范围上一定有x这个值
//划分数组<=x放左边，并且确保划分完成后<=x的最后一个数字是x

int partition(int l,int r,int x){
//a:arr[l...a-1]范围是<=x的区域
//xi: 记录在<=x区域上任何一个x的位置，哪一个都可以
int a=l,xi=0;
for(int i=l;i<=r;i++){
	//不管哪一个分支，都会有i++
	if(arr[i]<=x){
		swap(a,i);
		if(arr[a]==x){
			xi=a;
		}
		a++;	
	}
	//if arr[i] >x 不调整 直接i++

}
	//<=x    x  >x 
	//l.... a-1 a......r
	swap(xi,a-1);
	return a-1;

}
```

## 优化

中间放所有等于x的数![[Pasted image 20260422174745.png]]
等于x的区域 一批一次划分过程完成； 小于x 大于x再自己内部选择划分。

![[Pasted image 20260422175240.png]]
设置两个区域，小于与大于，遇到什么情况 向各自发货。
*a* 小于区域的越界位置，*b* 大于区域的越界位置。一直遍历的下标 *i*

1. < 的情况  a,i 交换 ，a++（小于区域扩充）,i++（继续往右看别的数，这里交换的数是从左到右遍历看过的）
2. \=\=的情况 ，i++
3. >5的情况, b,i交换，b-- （大于区域扩充）,i不变（刚从右边换过来一个数字，还没有看。）

时间复杂度为O(n),所有数字过了一遍，i永远不回退，什么时候超过b了结束

荷兰国旗划分。

返回=x的左边界与右边界。接下来调用递归 左侧与右侧![[Pasted image 20260422180159.png]]


一次搞定一批x,以后再也遇不到x了。

```java
public static int first,last;

//已知arr[l...r]范围上一定有x这个值
//划分数组 <x 放左边 ==x放中间 >x放右边
//把全局变量first,last更新为==x的左右边界
public static void partition(int l,int r,int x){
	first=l;
	last=r;
	int i=l;
	while(i<=last){
		if(arr[i]==x){
			i++;
		}else if(arr[i]<x){
			swap(first++,i++);
		}else{
			swap(i,last--);
		}
	}

}
```

```java
partitiion(l,r,x);
//为了防止底层的递归过程覆盖全局变
//这里使用临时变量记录first,last

int left=first;
int right=last;
quickSort(l,left-1);
quickSort(right+1,r);
```


过程：在当前范围上选择一个数字x,利用荷兰国旗问题进行数组的划分，<x =x >x 对<x 范围重复划分过程，对>x重复划分过程

优化点：选出一个数字x,数组在划分时会搞定所有值是x的数字

## 复杂度

为什么随机选？按照期望估计时间复杂度。而不是最差情况估计。没有随机行为的固定流程可以看最差情况。

随机行为 ：

x处于很正的位置 \最好，或者离中点远的位置 \最差。
求期望 ，最后时间空间复杂度与最好的情况一样。T:O(n\*logn);S:O(logn)
