## 递归


- 过程(高度总结版)：**左部分排好序，右部分排好序，利用merge过程让左右整体有序**。


调用，返回。f(0,0)和f(1,1)返回，f(0,1)收到左侧有序和右侧的有序merge过程,左右指针，额外辅助数组，比较 ![[Pasted image 20260420215227.png]]


辅助数组刷回原数组
f(0,2)左侧完结，f(0,2)调用右侧，返回2；
![[Pasted image 20260420215417.png]]

谁小拷贝谁，右指针没了 将左边剩余数字放进辅助数组，再刷回原数组下标![[Pasted image 20260420215545.png]]

代码的实现
```java
public static int MAXN = 501;
public static int[] arr=new int[MAXN];
public static int[] help=new int[MAXN];


public static void mergeSort(int l,int r)
{
	if(l==r)
		return ;
	int m=(l+r)/2;
	mergeSort(l,m);
	mergeSort(m+1,m);
	merge(l,m,r);
}



public static void merge(int l,int m,int r)
{
	int i=l; //辅助数组被填到了什么位置
	int a=l;
	int b=m+1;
	
	while(a<=m&&b<=r)  //左右两侧都没有耗尽的话
	{
		//谁小拷贝谁 
		help[i++]=arr[a]<=arr[b]?arr[a++]:arr[b++];
	}

	//左侧指针与右侧指针必有一个越界 一个不越界
	
	//下面的两个while只会命中一个
	while(a<=m)
	{
		help[i++]=arr[a++];
	}
	while(b<=r)
	{
		help[i++]=arr[b++];
	}
	
	for(i=l;i<=r;i++)
	{
		arr[i]=help[i];
	}
}

```

```java
public static void mergeSort()
{
	for(int l,m,r,step=1;step<n;step<=1){
		l=0;
		while(l<n){
		m=l+step-1;
		//右侧开头 越界 说明数组后面没东西了 没有右侧了
		if(m+1>=n)
			break;
		
		//有右侧,求右侧的右边界
		r=Math.min(l+(step<<1)-1,n-1);
		merge(l,m,r);
		//下一组
		l=r+1;
		}
	
	}

}
```

O(n\*logn)
