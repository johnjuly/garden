## 稳定性

- 稳定性：排完序后 同样的值 保证相对次序不变。第一个1 第二个1 。
- [[三种排序|选择排序]]:0-n-1上选择一个最小值 换到0位置，不稳定，第一个三 跨越 到了后面![[Pasted image 20260503212857.png]]
- [[三种排序|冒泡排序]]：稳定。相等不交换![[Pasted image 20260503213048.png]]
- [[三种排序|插入排序]]。稳定。来一个数往前插入，不再比前面的数小停止交换![[Pasted image 20260503213159.png]]
- [[归并排序]]。左边有序，右边有序，合并。相等先拷贝左侧![[Pasted image 20260503213258.png]]
- [[随机快速排序|快速排序]]。不稳定。一发货 4和5交换 ![[Pasted image 20260503213412.png]]
- [[堆结构和堆排序|堆排序]]，不稳定。![[Pasted image 20260503213458.png]]


- 计数排序 [[基数排序]] 稳定。



## 总结


| 排序算法          | 时间         | 空间      | 稳定性 |
| ------------- | ---------- | ------- | --- |
| SelectionSort | O(N^2)     | O(1)    | 无   |
| BubbleSort    | O(N^2)     | O(1)    | 有   |
| InsertionSort | O(N^2)     | O(1)    | 有   |
| MergeSort     | O(N\*logN) | O(N)    | 有   |
| QuickSort     | O(N\*logN) | O(logN) | 无   |
| HeapSort      | O(N\*logN) | O(1)    | 无   |
| CountSort     | O(N)       | O(M)    | 有   |
| RadixSort     | O(N)       | O(M)    | 有   |


- 数据量非常小的情况下可以做到非常迅速：插入排序。
- 性能优异，实现简单且利于改进(不同业务选择**不同划分策略**) 不在乎稳定性：随机快排
- 性能优异 不在乎额外空间占用 有稳定性 ： 归并排序
- 性能优异 额外空间占用要求O(1) 不在乎稳定性 ：堆排序
