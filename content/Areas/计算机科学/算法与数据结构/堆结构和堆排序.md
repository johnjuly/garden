## 堆结构

即完全二叉树结构。

完全二叉树和数组前缀范围的对应![[Pasted image 20260424100233.png]]

从左往右依次变满.
通过连续的一段想像二叉树的结构。
- 单独的变量**size** 管理完全二叉树的大小，超过的下标不存在。 
- 任何一个节点 i 父位置：**i-1/2**;0 节点除外。
- 任何一个节点左孩子：**i*\2+1**. 右孩子：**i\*2+2;**
算出来的下标小于size才存在。比如 size=6,

---

堆的定义：

大根堆 ： 任何一颗子树的最大值在子树的顶部。Heap insert.看与父亲节点 i-1/2,调整的是数组中的位置，想像 二叉树。当插入数的时候不停往上看直到干不掉父节点 停。

### 向上调整

i位置的数，若变大了，向上调整；变小了，向下调整。

```java
// i 位置的数，向上调整最大根堆
//arr[i]=x,x是新来的，往上看，直到不比父节点大，或者来到0位置
public static void helpInsert(int[] arr,int i){

	//i->父：(i-1)/2
	//i来到0的位置也可包含，不比自己大
	while(arr[i]>arr[i-1/2]){
		swap(arr[i],arr[i-1]);
		i=i-1/2; //来到父节点的位置
	}
}




```


### 向下调整

向下调整，判断是否有孩子 下标与size比较。与左右孩子中较大的数 比较交换往下沉。往下直到最好的孩子也不比自己大。

```java
//i位置的数变小了。向下调整最大根堆
//当前堆的大小为size
//    i
//  左  右
public static void hepify(int[] arr,int i,int size){
	int l=i*2+1;
	
	while(l<size){
		//有左孩子，l
		//右孩子 , l+1
		//评选最强的孩子是哪个下标的孩子
		//l+1<size说明有右孩子  并且 右孩子>左孩子 ；两个条件成立 右孩子才是最强下标。
		int best=l+1<size&&arr[l+1]>arr[l]?l+1:l;
		//评选了最强的孩子，接下来 当前的数和最强孩子之间选最强下标
		best=arr[best]>arr[i]?best:i;
		if(best==i){
			//不用往下扎了.最强的是自己。停止往下扎的操作
			break;
		}
		swap(arr,best,i);
		i=best;
		l=i*2+1;
	}

}
```


高度与节点数的关系。 <=N  logN 看接近于2的几次方。

往上走往下走 都是O(logn).完全二叉树的结构所决定的。


## 堆排序

1. 顶->底 建堆 O(nlogn)
2. 调整过程 O(nlogn)

先把整个数组变成大根堆。不断把最大的值放到最后，然后减少堆的大小

```java
//从顶到底建立大根堆 O(n*logn)
public static void heapSort(int[]arr){

	int n=arr.length;
	for(int i=0;i<n;i++){
		heapInsert(arr,i);
	}
	int size=n;
	//什么时候size
	while(size>1){
		//最后一个下标和0交换 ，减少堆的大小
		swap(arr,0,--size);
		//堆向下调整
		heapify(arr,0,size);
	}
}
```


从顶到底建堆，大小不断增加![[Pasted image 20260424105407.png]]

收敛 O(nlogn)；  
向下调整排序 同样O(nlogn) 反过来 大小不断减小。
