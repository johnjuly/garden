## 用栈实现队列

![[Pasted image 20260414125556.png]]
两个栈： in 和 out

倒数据 遵循两个原则
1. out空了，才能倒
2. 如果要倒数据，in 必须倒完



```cpp
stack<int> in;
stack<int> out;

//倒数据
//从in栈把数据倒入out,遵循两个原则
void inToOut(){
	if(out.empty()){
		while(!in.empty()){
			out.push(in.pop())
		}
	}

}

//加入一个数 看能不能倒数据 能倒就倒
void push(int x){
	in.push(x);
	inToOut();
}

int pop(){
	inToOut();
	return out.pop();
}

int peek(){
	inToOut();
	return out.peek();
}

bool empty(){
	return in.empty()&&out.empty();
}

```

时间复杂度:
每个数 最多进 in 一次；    出in一次，进 out 一次 （倒数据）；   出out (用户调用)一次
均摊下来 big O 1


## 队列实现栈

![[Pasted image 20260414131030.png]]
O(N)
加入x之前看队列大小 =移动的次数

```cpp
void push(int x){
	int n = queue.size();
	queue.offer(x);
	for(int i=0;i<n;i++){
		queue.offer(queue.poll());
	}

}
```
