## 分类
![[Pasted image 20260415204343.png]]
两大类：
### sequence containers

**array** 前后无法扩充，固定长度
vector 起点不可动，后面可以动 。分配器帮忙处理内存 自动扩充。
deque 两端可进可出
list 双向链表
**forward-list** 单向链表


### associative containers (key-value):查找，排序

multi:key可以重复

set/multiset: 实现：一般 红黑树 高度平衡：左右自己调整到差不多一样高，查找的时候，不会有最坏的情况一直往某一个子树找. set不分key/value.

map/multimap: 每个节点有key&value;

c11新出现
### **unordered containers**其实是一种associative containers, hash table
![[Pasted image 20260415204946.png]]

数据结构为哈希表 每一个篮子(buket) 代表一个链表, separate chaining  目前采用的方法 分开避免哈希冲突。


## 测试

array中放50万个元素，试图去找一个目标


四个函数

- 输入一个要找的目标 数值`long get_a_target_long()`
- 输入一个要找的目标 对象 指针`string get_a_target_string()`
![[Pasted image 20260415210258.png]]
用于quicksort:
- 比较两个long相不相等`int compareLongs(const void* a,const void* b)`
- 比较两个string相不相等
![[Pasted image 20260415210238.png]]


**排序之后二分查找**

```cpp
#include <array>
#include <iostream>
#include <ctime>
#include <cstdlib> //qsort,bsearch,NULL

namespace test01{
void test_array(){
array<long,ASIZE> c; //类型 大小

for(long i=0;i<ASIZE;++i){
	c[i]=rand();
}

array.size();
array.front();
array.back()
array.data() //传回 起始地址

long target=get_a_target_long();

//排序
//记录一个动作花费的时间
timeStart=clock(); //程序从开始到现在
qsort(c.data(),ASIZE,sizeof(long),compareLongs);
long* pItem=(long*)bsearch(&target,(c.data()),ASIZE,sizeof(long),compareLongs);
cout<<"qsort()+bsearch(),milli-seconds:"<<(clock()-timeStart)<<endl;

if(pItem!=NULL)
	cout<<"found,"<<*pItem<<endl;
else
	cout<<"not found!"<<endl;

}

}
```
