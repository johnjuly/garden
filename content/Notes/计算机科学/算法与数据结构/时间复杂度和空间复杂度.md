## 时间复杂度

常数操作[^1]：位运算 算术运算 寻址 哈希

非常数时间： 链表 ，不固定时间。

[^1]: 固定时间的操作，执行时间和数据量无关


时间复杂度 ： 只要高阶项不要低阶项，不要常数项 的操作次数表达式；最差情况估计 插入排序 O(N) O($N^2$).  算法运行时间和数据量大小的关系。数据量很大时，相当的本质的关系，排除了低阶项、常数时间的干扰。


## 空间复杂度

入参与返回的空间无关；额外空间

不要用代码结构判断时间复杂度，充分理解算法流程
一个循环，但是O(N*N)
```cpp
int n=arr.size();
int end=n-1,i=0;
while(end>0){
	if(arr[i]>arr[i+1]){
		swap(arr,i,i+1);
	}
	if(i<end-1){
		i++;
	}else{
		end--;
		i=0;
	}
}
```
