## 栈的实现


### 先序

> 中 左 右

栈不为空 弹出打印

压入的时候先压右再压左

右如果不为空先压右，左不为空压左


```java

public static void preOrder(Treenode head){
	Stack<TreeNode> stack =new Satck<>();
	stack.push(head);
	while(!stack.isEmpty()){
		head=stack.pop();
		System.out.print(head.val+" ");
		if(head.right!=null){
			stack.push(head.right);
		}
		if(head.left!=null){
			stack.push(head.left);
		}
	
	System.outprintln();
	}
	
}
```


### 中序

![[Pasted image 20260416154029.png]]
1. 来到子树头，子树的左边界一直进栈，直到遍历完
2. 从栈里弹出节点打印，节点的右树重复步骤一，压左边界
3. 直到没有子树且栈空



对于任何一个节点，处理完自己的左树，自己，然后右边；处理完65才轮到2


```java
public static void inOrder(TreeNode head){

	if(head!=null){
		Stack<TreeNode> stack =new Stack<>();
		while(!stack.isEmpty()||head!=null){
			if(head!=null){
				stack.push(head);
				head=head.left; //压入，head往左移动
			}else{
				head=stack.pop(); //head从左孩子回 
				System.out.print(head.val+" "); //弹出 打印
				
				
				head=head.right; // 跑到右孩子
			
			}
		
		}
		System.out.println();
	
	}
}
```

### 后序 遍历两个栈



两个先序

先：中左右
先':中右左

后：左右中（先'的反转）

实现：两个栈，弹出先不打印，再放入一个栈里。按照中右左的顺序进栈

```java
public static void posOrderTwoStacks(TreeNode head){
	if(head!=null){
		Stack<TreeNode> stack=new Stack<>();
		Stack<TreeNode> collect=new Stack<>();
		stack.push(head);
		while(!stack.isEmpty()){
			head=stack.pop();
			collect.push(head);
			if(head.left!=null){
				stack.push(head.left);
			}
			if(head.right!=null){
				stack.push(head.right);
			}
		
		}
		
		while(!collect.isEmpty()){
			System.out.print(collect.pop().val+" ");
		}
		System.out.println();
	
	}
	
}

```


### 后序 一个栈

加入一个概念，上次打印的节点

```java
if(h!=null){
	Stack<TreeNode> stack=new Stack<>();
	stack.push(h);
	//h 哨兵，一开始的含义头节点，之后的含义上一次打印的节点
	
	while(!stack.isEmpty()){
		TreeNode cur=stack.peek();
		
		
		if(cur.left!=null&&h!=cur.left&&h!=cur.right){
			//有左树且左树没有处理过
			stack.push(cur.left);
		}else if(cur.right!=null&&h!=cur.right){
			//有右树且右树没有处理过
			stack.push(cur.right);
		}else {
			//左树 右树 没有 或者 都处理过了
			
			System.out.print(cur.val+" ");
			h=stack.pop();
		}
	
	}
	System.out.println()
;
}

```

## 复杂度分析

### 递归

任何一个节点如果不空，就会来到它三次
时间复杂度：O(n)

### 非递归

时间复杂度：O(n)  每一个节点 进栈和出栈的次数有限


空间复杂度：都是O(h) h:树的高度。 栈同样，也是压一个路径。弹出回到上层。
