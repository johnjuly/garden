## 1 accumulate

> 累计传进去的计算。

两个版本：
- 版本一：接受头尾两个指针以及初值   

```cpp
template <class InputIterator,class T>
T accumulate(InputIterator first,InputIterator last,T init){
	for(;first != last; ++first)
		//将元素累加至初值init身上
		init=init+*first;
	return init;
	
}
```
- 版本二：版本一的基础上加上一个二元操作数

```cpp
template <class InputIterator,class T,class BinaryOperation>
T accumulate(InputIterator first,InputIterator last,T init,BinaryOperation binary_op){
	for(;first != last; ++first)
		init=binary_op(init,*first);
	return init;
	
}
```

- 例子： 
```cpp
#include <iostream>       //std::cout
#include <functional>     //std::minus    
#include <numeric>        //std::accumulate
namespace jj34
{
int myfunc(int x,int y){return x+2*y;}

struct myclass{
	int operator()(int x,int y){return x+3*y;}
}myobj;

void test_accumulate()
{
	int init=100;
	int nums[]= {10,20,30};
	
	cout<<"using default accumulate: ";
	cout<<accumulate(nums,nums+3,init);  //160
	cout<<'\n';
	
	cout<<"using functional's minus: ";
	cout<<accumulate(nums,nums+3,init,minus<int>());    //40 functor
	cout<<'\n';
	
	cout<<"using custom function: ";
	cout<<accumulate(nums,nums+3,init,myfunc); //220
	cout<<'\n';
	
	cout<<"using custom object: ";
	cout<<accumulate(nums,nums+3,init,myobj;  //200 
	cout<<'\n';

}


}


```



## 2 for_each

对容器范围内的每一个元素做一件事。
一个动作 f
```cpp
template <class InputIterator,class Function>
Function for_each(InputIterator first,InputIterator last,Function f)
{
	for(;first!=last;++first)
		f(*first);
	return f;
}
```

## 3 replace(\_if,\_copy)

```cpp
template<class ForwardIterator, class T>
void replace(ForwardIterator first,ForwardIterator last,const T& old_value,const T& new_value){
	//范围内所有等同于old_value者都以new_value取代
for(;first!=last;first++)
	if(*first==old_value)
		*first=new_value;
}
```


```cpp
template<class ForwardIterator, class T>
void replace_if(ForwardIterator first,ForwardIterator last,Predicate pred,const T& new_value){
	//范围内所有所有满足pred()为true的元素都以new_value取代
for(;first!=last;first++)
	if(pred(*first))
		*first=new_value;
}
```


```cpp
template<class ForwardIterator, class T>
OutputIterator replace_copy(ForwardIterator first,ForwardIterator last,OutputIterator result,const T& old_value,const T& new_value){
	//范围内所有等同于old_value者都以new_value放至新区间,不符合者原值放入新区间
for(;first!=last;++first,++result)
	*result=*first==old_value?new_value:*first;
return result;
}
```



## 4 count(\_if)

```cpp
template<class InputIterator, class T>
typename iterator_traits<InputIterator>::difference_type
count(InputIterator first,InputIterator last,const T& value){
	//定义一个初值为0的计数器n
	typename iterator_traits<InputIterator>::difference_type n=0;
	for(;first!=last;++first)  //遍历（循序搜寻）
	if(*first==value)   //如果元素值和value相等
		++n;            //计数器累加1
	return n;
}
```


```cpp
template<class InputIterator, class T>
typename iterator_traits<InputIterator>::difference_type
count_if(InputIterator first,InputIterator last,Predicate pred){
	//定义一个初值为0的计数器n
	typename iterator_traits<InputIterator>::difference_type n=0;
	for(;first!=last;++first)  //遍历（循序搜寻）
	if(pred(*first))   //如果元素带入pred的结果为true
		++n;            //计数器累加1
	return n;
}
```



> [! note]
> 容器**不带**成员函数count():
> 
> 	array, vector, list, forward_list, deque
> 
> 容器**带有**成员函数count():八个. [[6 测试四 关联式容器|关联式容器]]，由key找到data.一个小型数据库。
> 
> 	set/multiset, map/multimap; unordered_set/unordered_multiset;unordered_map/unordered_multimap







## 5 find(\_if)


```cpp
template<class InputIterator,class T>
InputIterator find(InputIterator first,InputIterator last,const T&value)
{
	while(first!=last&&*first!=value)
		++first;
	return first  //循序式搜寻/查找
}
```



```cpp
template<class InputIterator,class T>
InputIterator find_if(InputIterator first,InputIterator last,Predication pred)
{
	while(first!=last&&pred(*first))
		++first;
	return first  //循序式搜寻/查找
}
```

用红黑树和散列表做出来的八个容器带有成员函数find()



## 6 sort


源码很长。

- 关联式容器不带成员函数sort，也不用调用sort函数。已经排好序，元素放进去即形成了排好序的状态。
- 容器不带成员函数sort():array,vector,deque
- 容器带有成员函数sort():list,forward_list.(std的sort要求的是random access iterator,可以跳的，而这两种容器不可以跳)
- 标准库的算法不一定可以适用于所有容器
- 使用

```cpp

//using default comparison(operator <):
sort(myvec.begin(),myvec.begin()+4);

sort(myvec.begin(),myvec.begin()+4,myfunc);

sort(myvec.begin(),myvec.begin()+4,myobj);

//using reverse iterators and default comoparison(operator <):
sort(myvec.rbegin(),myvec.rend());
```



## binary_search

> 条件是：排序。


把工作交给了lower_bound去做。

```cpp
template<class ForwardIterator,class T>
bool binary_search(ForwardIterator first,ForwardIterator last,const T& val)
{
	first=std::lower_bound(fisrt,last,val);
	return (first!=last&&!(val<*first))
}
```

所获得的iterator 所指的位置即非end,目标值val也不小于首元素。

```cpp
template<class ForwardIterator,class T>
ForwardIterator lower_bound(ForwardIterator first,ForwardIterator last,const T& val)
{
	ForwardIterator it;
	iterator_traits<ForwardIterator>::difference_type count,step;
	count=distance(first,last);  //头跟尾的距离切出来
	while(count>0)
	{
		it=first;
		step=count/2;      //二分
		advance(it,step);
		
		if(*it<val){
			first=++it;
			count==step+1;
		}
		else count=step;
	
	}
	return first;
}
```
