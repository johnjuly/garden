## 起因

一直设置为黑暗模式，白天晚上一个色，白天有时会觉得太黯淡了。


## 原理


### 脚本

给解释器看的指令。

Ubuntu GNOME的主题通过`gsettings`控制。

- 查看当前主题：
```sh
gsettings get org.gnome.desktop.interface color-sheme
```
- 切换为浅色/深色：
```sh
gsettings set org.gnome.desktop.interface color-sheme "prefer-dark"/"prefer-light"
```

所以脚本的工作步骤是：获取当前时间——>判断应该使用什么模式——>调用`gsettings`

### service

一个配置文件，告诉[[systemd]]要运行的程序.
### timer

同上，告诉systemd什么时候执行。

### 完整链路

时间到(7:00/19:00)——>timer——>service——>bash process(shell script)——>gsettings——>修改主题


## 创建shell脚本

写入 ~/scripts/theme-switch.sh
```sh
#!/bin/bash

LIGHT_START=7
DARK_START=19

hour=$(date +%H)

if (( hour >= LIGHT_START && hour < DARK_START )); then
    mode="prefer-light"
else
    mode="prefer-dark"
fi


current=$(gsettings get org.gnome.desktop.interface color-scheme | tr -d "'")


if [ "$current" != "$mode" ]; then
    gsettings set org.gnome.desktop.interface color-scheme "$mode"
fi
```

添加执行权限：`chmod +x ~/scripts/theme-switch.sh`

## 创建 systemd Service

～/.config/systemd/user/theme-switch.service

```txt
[Unit]
Description=Auto Theme Switch


[Service]
Type=oneshot
ExecStart=%h/scripts/theme-switch.sh


[Install]
WantedBy=default.target
```

- Type=oneshot 表示执行一次后结束
- ExecStart 指定执行脚本路经
- WantedBy 表示用户登录桌面时自动运行

## 创建定时触发器

theme-light.timer

```txt
[Unit]
Description=Switch theme at 07:00


[Timer]
OnCalendar=*-*-* 07:00:00
Persistent=true
Unit=theme-switch.service


[Install]
WantedBy=timers.target
```

---

theme-dark.timer

```txt
[Unit]
Description=Switch theme at 19:00


[Timer]
OnCalendar=*-*-* 19:00:00
Persistent=true
Unit=theme-switch.service


[Install]
WantedBy=timers.target
```


## 启动服务

- 重新加载 systemd : `systemctl --user daemon-reload`
- 启用登录后自动执行：`systemctl --user enable theme-switch.service`
- 启用定时任务：`systemctl --user enable --now theme-light/dark.timer`

## 问题记录

### 1 脚本语法

bash 空格敏感。`date +%H`
`if [ "...`

命令后空格

### 2 Timer显示n/a

timer大小写敏感 `OnBootSec`

### 3 persistent = true代表？

如果电脑关机错过执行时间，开机后会补一次。

### 4 脚本中09无法解析

![[Pasted image 20260802170301.png]]

09在bash算术表达式中被理解为八进制数字 9

更改方法：

```sh
hour=$(date +%H)
hour=$((10#$hour))
```

`10#`都按十进制解释
