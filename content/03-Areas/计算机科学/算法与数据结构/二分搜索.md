## 寻找num

在一个**有序**(单调性)数组中找一个数字

```cpp
if(arr==null||arr.length==0){
	return false;
} 

//左右边界，搜索范围，中点位置
int l=0,r=arr.size()-1,m=0;
while(l<=r){
	m=(l+r)/2;
	if(arr[m]==num){
		return true;
	}else if(arr[m]>num){
		r=m-1;
	}else{
		l=m+1;
	}

}
return false;
```



## 寻找>=num最左

l m r，ans=-1初始值;
m>=num,记答案，往左二分；m<num,不记答案，往右二分。

l+(r-l)/2    //溢出。l出发，+一半的距离来到中点
```cpp
int l=0,r=arr.size()-1,m=0;
int ans=-1;


while(l<=r){  //二分的范围上有数
	//m=(l+r)/2;
	m=l+((r-l)>>1);  
	if(arr[m]>=num){
		ans=m;
		r=m-1;
	}else{
		l=m+1;
	}
	
	}
	return ans;
```



## 寻找<=num最右位置

```cpp
int l=0,r=arr.size()-1,m=0;
ans=-1;
while(l<=r){
	m=l+(r-l)/2;
	if(arr[m]<=num){
		ans=m;
		l=m+1;
	}else{
		r=m-1;
	}

}
return ans;
```


## 峰值问题

二分搜索不一定发生在有序数组上

某侧必有

画图 

1. 检查0位置
2. 检查n-1位置
3. 看中点
	1. 是峰值，返回
	2. 不是峰值，左>中点，左侧二分
	3. 不是峰值，右>中点，右侧二分



```cpp
int n=arr.size();
if(arr.length==1){
	return 0;  //-1 0 1 默认-1和越界位置是超小的值
}

//数组长度>=2且相邻两数不相等

//单独验证0位置和n-1位置是不是峰值点
if(arr[0]>arr[1]){
	return 0;
}
if(arr[n-1]>arr[n-2]){
	return n-1;
}

int l=1,r=n-2,m=0,ans=-1;

while(l<=r){
	m=l+(r-l)/2;
	
	
	//大  小
	//m-1 m
	//下降的曲线，左边上升的趋势
	if(arr[m-1]>arr[m]){
		r=m-1;
	}else if(arr[m]<arr[m+1]){
		l=m+1;
	}else{
		ans=m;
		break;
	}

}

return ans;
```
