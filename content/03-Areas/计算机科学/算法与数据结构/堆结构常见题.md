## 合并k个有序链表

- 使用小根堆。![[Pasted image 20260426142454.png]]
- 小根堆里节点个数：链表条数。
- k条链表，n个节点。 
- 方法1：收集所有节点到容器再排序 再依次串好 O(N)+==O(nlogn)==+o(n)，复杂度看最高阶，空间：O(n)
- 堆方法：T: O(n\*logk) ; S:O(k) .  k<=n;

数组里存放每条链表的头节点

```java

		//遍历所有链表的头节点，放入堆里去。

			heap.add(h);
		}
	}
	if(heap.isEmpty()){
		return null;
	}
	
	//先弹出一个节点做总头部 最后返回它
	ListNode h=heap.poll();
	ListNode pre=h;
	//弹出节点的下一个节点放入堆里去
	if(pre.next!=null){
		heap.add(pre.next);
	}
	while(!heap.isEmpty()){
		ListNode.cur=heap.poll();
		pre.next=cur;
		pre=cur;
		if(cur.next!=null){
			heap.add(cur.next);
		}
	}
	return h;

}
```

##  累加和减半的最少操作

#贪心

选择最大的数。
尽量选大的往下掉。
大根堆。数组中所有的数加到大根堆里。永远可以弹出最大的数字，减到一半再放回![[Pasted image 20260427213130.png]]
```java
public static int halveArray(int[] nums){
	//大根堆
	PriorityQueue<Double> heap= new PriorityQueue<>((a,b)->b.compareTo(a));
	double sum=0;
	for(int num:nums){
		heap.add((double) num);
		sum+=num;
	}
	//要减少的目标
	sum/=2;
	//做了几次操作
	int ans=0;
	for(double minus=0,cur;minus<sum;ans++,minus+=cur){
		//当前减少的幅度&即将进入大根堆的数
		cur=heap.poll()/2;
		heap.add(cur);
	}
	return ans;
	
}
```

- 复杂度分析 O(nlogn) 不做任何优化，把每一个数字减少一半，都做一次操作。次数小于等于n次。


### 优化

自己写堆 ，加 改 double ，控制精度 2^20次方，
准备一个long类型数组，将原数组的数变为long类型按堆的结构加入 heapify从最后一位进入到顶建立大根堆，O(n)
1. 留出位数 让它 够除
2. 自己写堆 建堆 弹出最大值算幅度 调堆 继续拿0位置的数重复该行为


```java
static int MAXN=100001;
static long[] heap = new long[MAXN];
static int size;

int halveArray(int[] nums){
	size=nums.length();
	long sum=0;
	for(int i=size-1;i>=0;i--){
		heap[i]=(long)nums[i]<<20;
		sum+=heap[i];
		heapify(i);
	}
	sum/=2;
	int ans=0;
	for(long minus=0;minus<sum;ans++){
		heap[0]/=2;
		minus+=heap[0];
		heapify(0);
	}
	return ans;

}
```
