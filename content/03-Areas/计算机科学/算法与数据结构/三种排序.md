选择排序：i-n-1范围上，找到最小值并放在i位置，然后i+1到n-1范围上继续。0-n-1,找，放0；1-n-1,找，放1；2-n-1,找，放2

```cpp
//数组长度不够
if(arr==null||arr.size()<2)
{
	return;
}

for(int minIndex,i=0;i<arr.size()-1;i++)
{
	//i-n-1 找 最小值，放到i位置
	
	
	minIndex=i; //i-n-1范围上，最小值在哪？一开始i位置，遍历后面
	for(int j=i+1;j<arr.size();j++)
	{
		if(arr[j]<arr[minIndex]){
			minIndex=j;
		}
	}
	swap(arr,i,MinIndex); 
}
```

冒泡排序

0-i范围上，相邻位置较大的数滚下去，最大值最终来到i位置，然后0-i-1范围继续；

0-n-1,大的数冒到n-1
0-n-2,
谁大谁往右
```cpp
if()

for(int end=arr.size()-1;end>0;end--)
{
	//0-n-1
	//0-n-2
	//0-n-3
	//0-end--
	
	for(int i=0;i<end;i++){
	//左边的数比右边的数大，交换
		if(arr[i]>arr[i+1]){
			swap(arr,i,i+1);
		}
	}
}

```


插入排序

0-i范围上已经有序，新来的从右到左滑到不再小的位置插入，然后继续。

摸牌
先认为0-0范围有序，新来的数在1位置上，往左插入，看哪里停；

```cpp
if()

//0-0 不用管
//0-1
//0-2
//0-3
//0-n-1

//i 右边界
for(int i=1;i<arr.size();i++){
	//0-i-1有序了，新来的数是[i],向左看
	
	//j：当前数的前一个位置； j+1:当前数
	//两个停止条件。左边有东西并且左边大于右边
	for(int j=i-1；j>=0&&arr[j]>arr[j+1];j--){
		swap(arr,j,j+1);
	}
}
```
