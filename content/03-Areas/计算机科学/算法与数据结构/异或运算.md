## 性质

1. 异或运算就是无进位相加。
2. 异或运算满足 交换律 结合律 。同一批数字异或结果只有一个。顺序不管。只和数量有关。
3. 0^n=n; n^n=0;
4. 整体异或和如果是x,整体中某个部分的异或和如果是y,那么剩下部分的异或和是x^y.

## 题目二：返回两个数的最大值

> 不用判断和比较语句



 ```cpp
 //0变1 1变0
 int flip(int n){
	 return n^1;
 }
 
 //非负返回1
 //负数返回0
 int sign(int n){
	 return flip(n>>>31);
 }
 
 
 //有溢出的风险
 int getMax1(int a,int b){
	 int c=a-b;
 
 //c非负，returnA->1
 //c负数，returnA->0
	 int returnA=sign(c);
	 int returnB=filp(returnA);
 //c非负，returnB->0
 //c负数，returnB->1
 //互斥
	 return a*returnA+b*returnB;
}

int getMax2(int a,int b){
	
	//c可能溢出 设置更多条件判断
	int c=a-b;
	//abc的符号
	int sa=sign(a);
	int sb=sign(b);
	int sc=sign(c);
	
	//判断AB符号是否不一样
	int diffAB=sa^sb;
	
	int sameAB=flip(diffAB);
	
	//返回A的条件：1.a和b的符号不一样并且a非负；2. a和b的符号一样 不可能溢出，看c,c非负
	//两者不可能同时成立，diffAB sameAB
	int returnA=diffAB*sa+ sameAB*sc;
	int returnB=flip(returnA); //互斥
	
	return a*returnA+b*returnB;
}
 
 ```

### 取出二进制数中最右侧的1

>  BrianKernighan算法


取反，取反加1,求与![[Pasted image 20260511112850.png]]
右侧为0,左侧都相反。

n&(~n+1);  即  n&(-n);


---

nums中只有两种数出现了奇数次，其他的数都出现了偶数次。

a和b分属两个阵营， 某一位不一样。

eor1=a^b;
eor2=a or b;
b or a =eor1^eor2;


```cpp

//eor1:a^b;

int eor1=0;
for(int num: nums){
	eor1^=num;
}

//提取最右侧的1,两者不一样的一位。状态。
int rightOne = eor1 & (-eor1);

//eor2只异或 在这一位上没有1的数。
int eor2=0;
for(int num:nums){
	if((num&rightOne)==0){
		//rightOne  : 0000 0100
		//num       : 0011 0110
		
		eor2^=num;
	}
}
return {eor2, eor1 ^ eor2};
```


## 题目六： 数组中只有1种数出现次数少于m次，其他数都出现了m次，返回出现次数小于m次的那种数

```cpp

int findNum(const vector<int>& arr,int m){
	//cnts[0]:第0位上有多少个1
	//cnts[1]:第1位上有多少个1
	//cnts[31]:第31位上有多少个1
	
	int cnts[31]={0};
	
	//统计每一位上1出现的次数
	for(int num:arr){
		for(int i=0;i<32;i++){
			cnts[i]+=(num>>i)&1;
		}
	}
	
	int ans=0;
	
	//如果某一位%m！=0
	//说明这个位属于那个出现次数少于m次的数
	for(int i=0;i<32;i++){
		if(cnts[i]%m!=0){
		//将第i位的1或到ans中去
			ans|=(1<<i);
		}
	}
	return ans;
}

```
