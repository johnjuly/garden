## 1 判断一个整数是不是2的幂

若n<0 ，false;

n->提取最右侧的1的状态 和n 相等 ，是2的幂 00101000  00001000, #BrianKernighan算法 提取出二进制最右侧的1


```cpp
bool isPowerOfTwo(int n){
	return n>0 && n==(n&-n);
}
```


## 2 判断一个整数是不是3的幂

如果一个数字是3的某次幂，那么这个数只有3这个质数因子，1162261467是int 型范围内最大的3的幂，3的19次方。
```cpp
bool isPowerOfTwo(int n){
	return n>0 && 1162261467%n==0;
}
```
